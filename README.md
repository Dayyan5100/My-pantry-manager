# My pantry manager
- built using Java
- XML layouts 
## Planned Features
- Add, view, edit and delete pantry ingredients
- Store pantry data between app sessions
- Suggest recipes only when every required ingredient is available
- Display recipe ingredients and even the preparation steps
- Save the pantry sorting preference
## Database
The application will use SQLite with SQLiteOpenHelper
SQLite was selected because pantry and recipe data can be stored locally
on the device without needing to have even a internet connection or a 
separate server and its easier to use and setup
## Current Progress
- The initial Android Studio project has been created
- The pantry features and database will be implemented in later stages
## Setup and Run
- download this repository 
- Open the project folder in Android Studio 
- Allow Gradle to sync and install any requested SDK components 
- Select an Android emulator or connected Android device 
- Then run
